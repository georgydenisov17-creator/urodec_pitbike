# Урод

2D-игра для телефона: школьник по прозвищу «Урод» едет на питбайке мимо «Жигулей», собирает бутылки «ГАЗЯВА» и катается на заднем колесе. Чистый HTML5 + CSS3 + JavaScript, без сборки, без библиотек и CDN. Вся графика и звук рисуются и генерируются кодом.

## Как запустить через GitHub Pages

1. Создай репозиторий на [github.com](https://github.com) (**New repository**, Public).
2. Загрузи 4 файла: **Add file → Upload files** → `index.html`, `style.css`, `game.js`, `README.md` → **Commit changes**.
3. Включи Pages: **Settings → Pages → Source: Deploy from a branch → Branch: main → / (root) → Save**.
4. Через 1–2 минуты открой `https://ИМЯ.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

## Как играть

Кнопки на экране (слева — скорость, справа — трюки):

- **ГАЗ** (удерживай) — разгон. **ТОРМОЗ** (удерживай) — торможение до полной остановки.
- **ПРЫЖОК** — один полный прыжок, в воздухе повторное нажатие игнорируется. Перепрыгивает одну «Жигули».
- **ВИЛИ** (удерживай) — езда на заднем колесе. Угол растёт, индикатор краснеет к 80°. Перед пределом отпусти кнопку. Пока едешь на заднем колесе, скорость чуть растёт и идут бонусные очки за каждый метр.

Столкновение с машиной или угол больше 80° — ролик падения (тап по экрану пропускает его), затем «Игра окончена».

Бутылки «ГАЗЯВА» дают +10 очков и копятся в кошельке. В **Магазине** за них покупаются скины: Классика (бесплатно), Неон (20), Камуфляж (40), Огонь (60), Космос (100). Покупки, выбранный скин, рекорд и настройка звука сохраняются в `localStorage`.

Максимальная скорость — 50 км/ч, потолок немного растёт со временем игры. Игра ставится на паузу при сворачивании вкладки.

**Клавиатура (для ПК):** ←/→ — тормоз/газ, Space — прыжок, ↑ или W — вили.

Все параметры (скорость, гравитация, лимит угла, цены, длительность роликов) лежат в объекте `CONFIG` в начале `game.js`.
